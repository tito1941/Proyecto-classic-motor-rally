# Classic Motor

Web para el rally y la concentración histórica Classic Motor. Ahora mismo las páginas están preparadas, pero su contenido sigue pendiente.

## Empezar

Instala las dependencias y arranca la aplicación:

```bash
npm install
npm start
```

Se abrirá en `http://localhost:4200/`.

## Páginas

- Inicio
- Catálogo de vehículos
- Programa e itinerario
- Inscripción
- Guía de estilo

Para generar la versión de producción, ejecuta `npm run build`.
